# App Voluntariado - Sede Tunjuelito

Aplicación móvil desarrollada con **React Native**, **Expo Router** y **TypeScript** para la gestión eficiente de turnos, reportes y control de voluntarios en la Sede Tunjuelito.

## 🚀 Características Principales
* **Autenticación Biométrica:** Inicio de sesión seguro utilizando la huella dactilar o reconocimiento facial del dispositivo (`expo-local-authentication`).
* **Gestión de Turnos y Roles:** Diferenciación de vistas y permisos entre Administradores y Voluntarios.
* **Generación de Reportes PDF:** Creación y exportación de reportes nativos en PDF (`expo-print` y `expo-sharing`).
* **Sistema de Notificaciones Local:** Alertas y avisos persistentes mediante `AsyncStorage` con filtrado por rol y destinatario.
* **Navegación por Tabs:** Estructura de navegación fluida basada en pestañas mediante Expo Router.

## 📱 Tecnologías Utilizadas
* React Native / Expo
* Expo Router
* TypeScript
* AsyncStorage
* Expo Local Authentication
* Expo Print & Sharing
